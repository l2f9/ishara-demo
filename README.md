# Ishara demo

A browser demo of Ishara (إشارة), a real-time sign recognition app for Arabic and English.

Open it on a device with a camera: https://l2f9.github.io/ishara-demo/

- Your camera video is processed on your device and is never uploaded or stored.
- This is a test version. If you choose to share a sign you taught, only numbers describing your hand joints, the name of the sign and your region are sent, and they are added to a shared library straight away so other testers get them too. You can delete everything you shared from the Sign library tab.
- This is a static, compiled build for trying the app. The source code is private and available on request.
